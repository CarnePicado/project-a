# Project B — Date and String Utils

Библиотека для работы с датами и строками.

## Возможности

### Работа с датами
- Получение текущей даты.
- Форматирование даты.
- Получение года из даты.

### Работа со строками
- Переворот строки.
- Подсчёт количества слов.
- Преобразование первых букв слов в заглавные.
